# Python Data Analytics Assignment 2

## Data Visualization Using Matplotlib and Seaborn

### Overview
This assignment focuses on data cleaning, exploratory data
analysis, and data visualization using Python.

The Seaborn Taxis dataset was used to analyse taxi trips,
fares, distances, payment methods, and pickup locations.

### Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Anaconda

### Dataset
Dataset: Seaborn Taxis Dataset

Original Dataset:
- 6,433 rows
- 14 columns

### Data Cleaning
- Identified missing values using isnull().
- Replaced missing payment values using mode.
- Removed rows with missing pickup or dropoff locations.
- Verified the cleaned dataset.

### Data Visualizations

1. Line Chart
   - Analysed taxi fares over time.

2. Bar Chart
   - Compared total fares across pickup boroughs.

3. Pie Chart
   - Visualized payment method distribution.

4. Histogram
   - Analysed taxi trip distance distribution.

5. Box Plot
   - Compared tip amounts across pickup boroughs.

6. Count Plot
   - Counted taxi trips by pickup borough.

7. Scatter Plot
   - Examined the relationship between distance and fare.

8. Correlation Heatmap
   - Analysed correlations between numerical variables.

9. Pair Plot
   - Compared distance, fare, tip, and total across pickup zones.
   - Used a sample of 500 trips for better visualization.

10. Violin Plot
    - Compared taxi fare distributions by payment method.

### Skills Demonstrated
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis
- Data Visualization
- Statistical Analysis
- Pandas Data Manipulation
- Matplotlib and Seaborn

### Conclusion
This assignment demonstrates how Python libraries
support data cleaning, analysis, and visualization.

Different visualization techniques were used to
explore taxi trip patterns and relationships between variables.
